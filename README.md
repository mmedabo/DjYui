# DJ YUI — Learn DJing with Your AI Tutor

A full-featured DJ learning app with YUI, your personal female AI DJ tutor. Learn DJing from scratch to pro through 12 progressive sessions, practice in a virtual DJ studio with real audio, and save your compositions.

## Features

- **YUI Tutor Character** — Animated SVG character with expressions, speech bubbles, and tips
- **12 Learning Sessions** — Beginner → Intermediate → Advanced → Pro curriculum
- **50+ Lessons** — Beatmatching, EQ, effects, transitions, harmonic mixing, scratching, set building
- **Interactive DJ Studio** — Virtual turntables, mixer, EQ, FX, waveform visualizer, crossfader
- **Real Audio Engine** — Web Audio API beat generation with BPM-synced patterns
- **XP & Progression** — Earn XP, complete challenges, level up
- **Compositions** — Record, name, and save your mixes

## Getting Started

```bash
npm install
npm run dev
```
